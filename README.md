# Pepper&Carrot source

A source for [Akidev](https://akidev.live/manga) that reads the episodes of
[Pepper&Carrot](https://www.peppercarrot.com) by David Revoy, in seven languages.

Pepper&Carrot is published under the [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
licence. The comic and its art belong to David Revoy; this repository holds only the plain-JSON definition that tells
the app where to find the episodes.

To use it, open Sources in Akidev, choose Add a repository and paste this repository's address.
